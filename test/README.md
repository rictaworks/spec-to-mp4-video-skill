# test

このリポジトリのテストを置く。

## 配置

| パス | 内容 |
|---|---|
| `test/support/` | テスト間で共有する読み込み処理とメッセージ定義。テストとして実行しない |
| `test/pr<PR番号>/` | PR ごとのテスト。`*.test.js` が Jest の対象になる |

`CLAUDE.md`「テストの配置と対象」に従い、テストは PR 番号のディレクトリへ置く。

## 対象

検証対象はリポジトリ内のファイル（主に `SKILL.md`）である。外部サーバへ接続しない。
接続先を持つテストを追加する場合は、接続先を環境変数で受け取り、値をテストコードへ直接書かない。

## 実行

```bash
npm ci
npm test
```

単一のディレクトリだけを実行する場合は次のとおり。

```bash
npx jest test/pr16
```

`test/support/skill.js` の実行経路をたどる場合は、トレースを有効にする。

```bash
SKILL_SUPPORT_TRACE=1 npm test
```
